What the results cover

Lookups use the exact versions in the input. Version ranges, local paths and unsupported tags are skipped. Environment markers and lockfile platform variants are not resolved, so the inventory may include packages for another target.

An OSV match identifies a published advisory for that version. Check affected configuration and fixed versions in the source advisory. A missing match means the query returned no advisory.
